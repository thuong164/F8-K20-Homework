Kỹ năng của tôi

Trang này tổng hợp các kỹ năng kỹ thuật, công cụ, công nghệ và những nội dung tôi đang tiếp tục học để phát triển bản thân trong lĩnh vực Công nghệ thông tin.

Kỹ năng kỹ thuật

HTML

Tôi có thể xây dựng cấu trúc trang web bằng HTML, sử dụng các thẻ semantic như header, nav, main, section, article và footer.

Mức độ: Intermediate

CSS

Tôi sử dụng CSS để định dạng giao diện, căn chỉnh bố cục, tạo màu sắc, khoảng cách, hiệu ứng hover và thiết kế giao diện thân thiện với người dùng.

Mức độ: Intermediate

JavaScript

Tôi đang học cách sử dụng JavaScript để xử lý tương tác trên website, làm việc với biến, hàm, sự kiện và thao tác cơ bản với nội dung trang web.

Mức độ: Beginner

Cơ sở dữ liệu

Tôi có kiến thức cơ bản về cơ sở dữ liệu quan hệ, biết cách thiết kế bảng, xác định khóa chính, khóa ngoại và viết một số câu truy vấn cơ bản bằng SQL.

Mức độ: Beginner

Trực quan hóa dữ liệu

Tôi có thể lựa chọn biểu đồ phù hợp để trình bày dữ liệu, ví dụ như biểu đồ cột, biểu đồ đường, biểu đồ tròn và dashboard tổng quan phục vụ phân tích.

Mức độ: Intermediate

Responsive Web Design

Tôi đang rèn luyện khả năng thiết kế website hiển thị tốt trên nhiều kích thước màn hình, từ máy tính đến điện thoại, bằng cách sử dụng bố cục linh hoạt.

Mức độ: Beginner

Công cụ & Công nghệ

Trong quá trình học tập và làm bài tập, tôi đã sử dụng một số công cụ hỗ trợ lập trình, thiết kế và quản lý dự án.

  • VS Code - Trình soạn thảo code thường dùng để viết HTML, CSS và JavaScript.
  • Git - Công cụ quản lý phiên bản, giúp theo dõi sự thay đổi của mã nguồn.
  • GitHub - Nền tảng lưu trữ source code và chia sẻ dự án cá nhân.
  • Figma - Công cụ thiết kế giao diện và phác thảo bố cục website.
  • Chrome DevTools - Công cụ kiểm tra HTML, CSS và debug giao diện trên trình duyệt.
  • Power BI - Công cụ trực quan hóa dữ liệu và xây dựng dashboard.
  • Python - Ngôn ngữ lập trình tôi sử dụng trong một số bài phân tích dữ liệu.
  • Streamlit - Framework hỗ trợ xây dựng web app phân tích dữ liệu bằng Python.

Đang học

Hiện tại, tôi đang tiếp tục học thêm các kiến thức mới để hoàn thiện kỹ năng lập trình và phát triển sản phẩm cá nhân.

  • JavaScript nâng cao: học sâu hơn về DOM, event, array method và xử lý dữ liệu.
  • Responsive Design: luyện tập thiết kế giao diện phù hợp với điện thoại, máy tính bảng và desktop.
  • Git & GitHub: học cách quản lý source code chuyên nghiệp hơn khi làm dự án.
  • UI/UX Design: tìm hiểu cách xây dựng giao diện dễ nhìn, dễ sử dụng và có trải nghiệm tốt.
  • Data Visualization: luyện tập chọn biểu đồ phù hợp và trình bày insight rõ ràng.
